# 前端活体检测使用说明

## 模型文件准备

face-api.js 需要加载模型文件才能工作。请按以下步骤操作：

### 1. 下载模型文件

从 face-api.js 官方仓库下载以下两个模型：
- `tiny_face_detector_model-weights_manifest.json` 和对应的 `.shard` 文件
- `face_landmark_68_model-weights_manifest.json` 和对应的 `.shard` 文件

下载地址：https://github.com/justadudewhohacks/face-api.js/tree/master/weights

### 2. 放置模型文件

在项目 `public` 目录下创建 `models` 文件夹，将下载的模型文件放入：

```
public/
└── models/
    ├── tiny_face_detector_model-weights_manifest.json
    ├── tiny_face_detector_model-shard1
    ├── face_landmark_68_model-weights_manifest.json
    └── face_landmark_68_model-shard1
```

### 3. 安装依赖

```bash
npm install
```

## 功能说明

### 前端活体检测流程

1. 学生打开摄像头考勤页面
2. 系统随机生成活体动作（眨眼/张嘴/摇头）
3. 实时检测面部关键点，判断动作完成
4. 动作完成后自动抓拍并提交后端

### 动作判定逻辑

- **眨眼**：计算 EAR (Eye Aspect Ratio)，检测到2次眨眼即通过
- **张嘴**：计算 MAR (Mouth Aspect Ratio)，持续张嘴10帧即通过
- **摇头**：追踪鼻尖坐标，左右偏移超过50像素即通过

## 测试步骤

1. 确保模型文件已正确放置
2. 重启开发服务器：`npm run dev`
3. 学生登录 → 摄像头考勤 → 按提示完成动作
4. 观察进度条和自动抓拍
