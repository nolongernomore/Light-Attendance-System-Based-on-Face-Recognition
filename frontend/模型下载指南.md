# face-api.js 模型下载与配置指南

## 问题原因

face-api.js 需要加载预训练模型文件才能进行人脸检测。当前提示"模型加载失败"是因为 `public/models/` 目录下缺少必需的模型文件。

## 解决步骤

### 步骤1：创建模型目录

在项目根目录下创建 `public/models/` 文件夹：

```bash
mkdir -p public/models
```

### 步骤2：下载模型文件

访问 face-api.js 官方模型仓库：
https://github.com/justadudewhohacks/face-api.js/tree/master/weights

需要下载以下文件（点击文件名 → 点击 "Raw" 按钮 → 右键另存为）：

**必需文件列表：**
1. `tiny_face_detector_model-weights_manifest.json`
2. `tiny_face_detector_model-shard1`
3. `face_landmark_68_model-weights_manifest.json`
4. `face_landmark_68_model-shard1`

### 步骤3：放置文件

将下载的4个文件放入 `public/models/` 目录，最终结构如下：

```
online/
├── public/
│   └── models/
│       ├── tiny_face_detector_model-weights_manifest.json
│       ├── tiny_face_detector_model-shard1
│       ├── face_landmark_68_model-weights_manifest.json
│       └── face_landmark_68_model-shard1
├── src/
└── package.json
```
