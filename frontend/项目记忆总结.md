# 班级考勤系统前端项目 - 记忆总结

## 项目概况

**技术栈**：Vue 3 (Composition API) + Vite + Element Plus + Axios + ECharts + face-api.js

**后端地址**：`http://26.6.49.51:8000`（Radmin VPN）

**项目目录**：`C:\StudyDatabase\online`

## 核心功能实现

### 1. 前端活体检测（face-api.js）
- 使用 WebRTC 调用摄像头
- 前端随机生成活体动作（眨眼/张嘴/摇头）
- 实时检测面部68个关键点
- 动作完成后自动抓拍并提交
- **模型文件位置**：`public/models/`（已正确放置）

### 2. 权限控制
- 角色：teacher / student
- Vue Router 全局守卫拦截
- Axios 自动携带 JWT Token

### 3. 教师端功能
- **课堂管理**：创建/编辑课程（course_code, course_name, term, description）
- **学生管理**：CRUD、批量导入Excel、人脸录入（单张照片）
- **考勤场次**：启动/查看/结束考勤
- **合照识别**：上传合照并识别参与学生
- **考勤记录**：按课程/学生筛选
- **Dashboard**：ECharts 图表展示出勤统计和情绪分布

### 4. 学生端功能
- **摄像头考勤**：前端活体检测 + 自动提交
- **我的记录**：查看个人考勤历史

## 关键修改记录

### 2026-05-10 重大架构调整

#### 1. 学生库与课程分离
- **Student.vue**：移除所有 `course_id` 相关代码，学生管理只负责全局学生库
- **Courses.vue**：新增学生管理功能（查看课程学生、添加学生到课程、批量导入、移除学生）
- **API变更**：
  - `POST /api/students` 只维护学生库，不加入课程
  - `POST /api/courses/{course_id}/students` 把学生加入课程
  - `GET /api/courses/{course_id}/students` 查询课程学生名单

#### 2. 课程管理优化
- **移除 course_code 字段**：统一使用 `course_id` 作为课程标识
- **新增删除课程功能**：`DELETE /api/courses/{course_id}`
- **课程字段**：只保留 `course_name`、`term`、`description`

#### 4. 学生端考勤优化
- **新API**：使用 `GET /api/attendance/my-sessions/active` 获取涉及自己的考勤
- **显示考勤信息**：在考勤界面显示当前考勤标题和课程名称
- **活体识别提示**：完成活体检测后显示"活体识别成功！正在提交考勤..."
- **后端返回结构适配**：
  ```json
  {
    "success": true/false,
    "code": "CHECKIN_SUCCESS" / "CHECKIN_FAILED_*",
    "data": {
      "failure_type": "timeout" / "recognition",
      "reason_code": "FACE_NOT_MATCHED" / "NO_FACE" 等
    }
  }
  ```
- **详细错误提示**：
  - 超时 → "考勤超时，请重试"
  - 未录入人脸 → "未录入人脸照片，请先录入"
  - 人脸不匹配 → "人脸识别失败，请重试"
  - 未检测到人脸 → "未检测到人脸，请重试"

#### 5. 考勤记录修复
- **MyRecords.vue**：修复字段名 `check_time` → `checkin_time`
- **Records.vue**：修复数据处理逻辑，确保返回数组
- **状态映射**：统一使用状态映射函数，移除硬编码

#### 6. 界面优化
- **删除首页统计**：移除 Dashboard 路由，教师登录后直接进入课程管理
- **修复登录跳转**：教师登录跳转到 `/teacher`（自动重定向到 courses）

### 2026-05-11 功能完善与优化

#### 1. 学生端人脸照片管理
- **新增页面**：`MyFace.vue` - 学生查看自己的人脸照片
- **字段修复**：`has_face` → `has_face_image` 适配后端返回
- **照片显示**：使用 `data_url` 格式（base64）显示照片
- **删除功能**：学生可删除自己的人脸照片
  - 接口：`DELETE /api/face/my-images/{image_id}`
  - 删除前弹出确认对话框
- **导航菜单**：在学生端添加"我的照片"菜单项

#### 2. 考勤流程优化
- **状态刷新**：重新开启摄像头时清空之前的考勤结果
- **抓拍照片展示**：考勤提交后显示传给后端的抓拍照片
- **画面稳定优化**：动作完成后等待1秒再抓拍，避免画面模糊
- **错误码完善**：支持所有人脸检测错误码的中文提示
  - `LIVENESS_TIMEOUT`、`LIVENESS_FAILED`、`FACE_NOT_ENROLLED`
  - `FACE_TEMPLATE_INCOMPATIBLE`、`FACE_SERVICE_TIMEOUT`
  - `INVALID_IMAGE`、`NO_FACE`、`MULTIPLE_FACE`
  - `LOW_QUALITY`、`UNKNOWN_FACE`、`FACE_SERVICE_ERROR`

#### 3. 合照识别功能重构
- **接口变更**：不再依赖考勤系统，独立的合照记录
  - `POST /api/group-photo/recognize` - 识别合照
  - `GET /api/group-photo/records` - 查询历史记录
  - `DELETE /api/group-photo/records/{record_id}` - 删除记录
  - `GET /api/group-photo/records/export` - 导出Excel
- **参数调整**：
  - 移除 `session_id`（不再关联考勤）
  - `activity_name` 和 `activity_date` 改为可选
  - 保留 `course_id`（可选，指定学生库范围）
- **返回结构**：
  ```json
  {
    "record": {
      "total_faces": 5,
      "matched_count": 3,
      "unknown_count": 2,
      "recognized_student_count": 3,
      "emotion_summary": { "happy": 3, "neutral": 2 },
      "students": [...]
    }
  }
  ```
- **功能增强**：
  - 上传合照预览
  - 历史记录折叠展开显示
  - 超时时间延长至60秒
  - 超时后自动刷新查看结果
  - 删除记录功能（带确认）
  - Excel导出功能

#### 4. 情绪分析功能集成
- **单人考勤情绪**：
  - 显示中文情绪名称（高兴、平静、悲伤等）
  - 显示情绪置信度百分比
  - 情绪数据写入 `attendance_records` 和 `emotion_records`
- **合照识别情绪**：
  - 每个识别学生包含情绪分析
  - 显示情绪汇总统计（`emotion_summary`）
  - 情绪数据写入 `group_photo_record_students` 和 `emotion_records`
- **考勤记录情绪映射**：
  - `MyRecords.vue` 和 `Records.vue` 显示中文情绪
  - 7种基本情绪映射（happy→高兴, neutral→平静等）

#### 5. 数据统计功能（评分要求）
- **学生参与统计**（合照识别）：
  - 统计数字：总活动数、总参与人次、参与学生数、情绪分析总数
  - 参与次数表格：学号、姓名、班级、专业、参与次数
  - 柱状图：Top 10 参与学生
  - 折线图：活动趋势（按时间）
  - 饼图：情绪分布统计
- **情绪统计**（考勤记录）：
  - 统计数字：总记录数、有情绪数据记录数
  - 饼图：情绪分布
  - 统计表：各情绪人次和占比
- **数据完整性**：记录学号、姓名、识别时间、情绪类型、置信度

#### 6. 考勤记录优化
- **字段修复**：
  - 课程和场次显示：`course_id` → "课程 1"，`session_id` → "场次 15"
  - 后端缺少 `course_name` 和 `session_title` 字段时的临时方案
- **Excel导出**：
  - 接口：`GET /api/export/attendance`
  - 支持按课程ID和学号筛选
  - 文件命名：`考勤记录_课程1_2026-5-11.xlsx`

#### 7. 人脸录入方式改变
- **从摄像头拍照改为上传照片**：
  - 移除 video、canvas 元素和摄像头调用
  - 使用 `el-upload` 组件支持拖拽上传
  - 限制上传一张图片，支持所有图片格式
  - 简化操作流程，提升用户体验

#### 8. 性能优化
- **图表实例管理**：
  - `Records.vue`：管理情绪饼图实例
  - `GroupPhoto.vue`：管理3个图表实例（柱状图、折线图、饼图）
  - 每次初始化前先调用 `dispose()` 销毁旧实例
  - 避免内存泄漏和重复渲染
- **响应速度提升**：
  - 减少浏览器内存占用
  - 提升页面切换和数据刷新速度

### API 对齐修改（历史记录）
1. **登录接口**：`/api/auth/login`，返回 `data.access_token`
2. **人脸录入**：改为单张照片，接口 `/api/face/enroll`，字段 `file`（单张）
3. **考勤提交**：添加 `session_id`、`liveness_passed` 字段
4. **学生字段**：使用 `major`（专业）而非 `class_name`

### 性能优化
- **考勤列表懒加载**：只在展开时加载学生记录，大幅提升渲染速度
- **移除并发查询**：学生列表直接使用后端返回的 `has_face_image` 字段
