# 班级人脸考勤系统前端 README

## 项目定位

这是班级人脸考勤系统的前端项目，面向教师端和学生端两类用户。教师负责课程、学生库、人脸照片、考勤场次、合照识别和统计导出；学生负责摄像头考勤、查看本人记录和管理本人照片。

后端地址在 `src/api/request.js` 中配置，当前为：

```js
baseURL: import.meta.env.VITE_API_BASE_URL || 'http://127.0.0.1:8000'
```

后端地址变化时，只需要修改这里。

## 技术栈

- Vue 3 + Vite
- Vue Router
- Axios
- Element Plus + Element Plus Icons
- ECharts
- face-api.js

## 快速启动

```bash
npm install
npm run dev
```

开发服务默认端口为 `3000`，配置在 `vite.config.js`。

常用账号：

```text
教师：teacher / 123456
学生：学号 / 学号
```

## 路由

| 用户 | 路径 | 页面 |
| --- | --- | --- |
| 公共 | `/login` | 登录 |
| 教师 | `/teacher/courses` | 课程管理 |
| 教师 | `/teacher/sessions` | 考勤场次 |
| 教师 | `/teacher/student` | 学生管理 |
| 教师 | `/teacher/group-photo` | 合照识别 |
| 教师 | `/teacher/records` | 考勤记录 |
| 学生 | `/student/checkin` | 摄像头考勤 |
| 学生 | `/student/my-records` | 我的记录 |
| 学生 | `/student/my-face` | 我的照片 |

路由守卫读取 `localStorage.token` 和 `localStorage.role`。未登录或角色不匹配时跳回 `/login`。

## 接口约定

`src/api/request.js` 统一封装 Axios：

- 请求自动添加 `Authorization: Bearer <token>`。
- 响应拦截器直接返回 `res.data`。
- 收到 `401` 时清空本地登录态并跳转登录页。
- 默认超时时间为 `15000ms`，合照识别单独设置为 `60000ms`。

主要接口分组：

| 模块 | 主要接口 |
| --- | --- |
| 登录 | `POST /api/auth/login` |
| 课程 | `/api/courses`、`/api/courses/{id}/students` |
| 学生库 | `/api/students`、`/api/students/import` |
| 人脸照片 | `/api/face/enroll`、`/api/face/my-status`、`/api/face/my-image`、`/api/face/my-images/{id}` |
| 考勤 | `/api/attendance/sessions`、`/api/attendance/my-sessions/active`、`/api/attendance/checkin`、`/api/attendance/records`、`/api/attendance/my-records` |
| 合照 | `/api/group-photo/recognize`、`/api/group-photo/records`、`/api/group-photo/records/export` |
| 统计导出 | `/api/stats/*`、`/api/export/attendance` |

## 核心业务流程

教师端：

1. 登录后进入课程管理。
2. 创建或编辑课程。
3. 在学生管理中维护全局学生库，可手动新增或批量导入。
4. 在课程管理中把学生加入课程名单。
5. 给学生上传人脸照片。
6. 启动考勤场次，查看、关闭或删除场次。
7. 在考勤记录中筛选、查看情绪统计并导出 Excel。
8. 上传合照识别参与学生，查看历史记录、参与统计、情绪分布并导出。

学生端：

1. 使用学号登录。
2. 在摄像头考勤页读取自己可参加的进行中考勤。
3. 浏览器授权摄像头。
4. 前端使用 face-api.js 完成眨眼、张嘴或摇头检测。
5. 动作完成后延迟抓拍并提交给后端。
6. 在我的记录中查看考勤结果，在我的照片中查看或删除本人照片。

## 活体检测模型

`Checkin.vue` 会从 `/models` 加载以下文件：

```text
public/models/tiny_face_detector_model-weights_manifest.json
public/models/tiny_face_detector_model-shard1
public/models/face_landmark_68_model-weights_manifest.json
public/models/face_landmark_68_model-shard1
```

这些文件已经放在项目中。若重新部署时缺失，按 `模型下载指南.md` 补齐。摄像头能力依赖浏览器权限，生产环境通常需要 HTTPS 或 localhost。

## 当前约定

- 学生库和课程名单是两个概念：`Student.vue` 管全局学生库，`Courses.vue` 管课程名单。
- 学生账号由后端创建，默认用户名和密码都是学号。
- 人脸录入采用上传单张图片，不再使用教师端摄像头拍照。
- 合照识别独立于考勤场次，`course_id` 可选；填写时只在指定课程名单内匹配。
- 情绪信息在考勤记录和合照识别页面做中文映射展示。
- 构建命令为 `npm run build`，输出目录为 `dist/`。
